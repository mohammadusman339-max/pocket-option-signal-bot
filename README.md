# Pocket Option Multi-Currency Signal Bot

An educational trading signal dashboard for multiple currency pairs.

## Features

- Multiple forex currency pairs
- EMA 9 and EMA 21 trend analysis
- UP and DOWN trend bias
- Market price chart
- Selectable chart intervals
- Simple mobile-friendly dashboard

## Supported Currency Pairs

- EUR/USD
- GBP/USD
- USD/JPY
- AUD/USD
- USD/CAD
- USD/CHF
- NZD/USD
- EUR/GBP
- EUR/JPY
- GBP/JPY

## Requirements

- Python 3.10 or newer
- Streamlit
- Pandas
- yfinance

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the App

```bash
streamlit run app.py
```

## Important Disclaimer

This project is for educational purposes only.

Signals are based on moving averages and are not guaranteed to be accurate or profitable.

Market data may be delayed or different from Pocket Option prices.

Always test using a demo account before considering real-money trading.
